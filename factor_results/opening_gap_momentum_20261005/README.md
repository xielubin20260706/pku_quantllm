# 开盘跳空动量因子挖掘

本目录归档 Issue #2 的因子挖掘阶段结果。实验使用 18 条围绕隔夜开盘跳空、跳空波动、跳空事件及日内/多日动量的状态流，固定随机种子 `20261005`，每轮 16 个候选，共 4 轮、64 个唯一候选。

## 结果文件

- `top20.csv`：按研究评分降序排序的 Top20，产物路径为本目录内相对路径。
- `selection.json`：候选计数、评分期、评分解释及入选配置。
- `manifest.json`：数据范围、缓存标签、搜索空间、种子、评分和指标池配置。
- `pool.json`：18 条定向状态流的完整名单。
- `search_completion.json`、`mining.log`：完成数量和运行记录。
- `artifacts/top20/`：Top20 的 PathMatch 查找表产物；不是公司回测持仓，也不是独立 OHLCV 因子实现。

## 评分口径与边界

- 日线数据范围：2016-01-01 至 2024-12-31；研究评分期：2020-01-01 至 2024-12-31。
- lookup 标签：未来 5 根 bar 的标签，阈值 ±50bp / ±100bp；分组 Sharpe 评分 horizons 为 1、5、10。
- 评分来自开盘价部分策略代理，使用单调性连续惩罚，不执行硬单调门槛；不是原版 Panda native v5，也不是公司完整回测。
- 此次 64 个结果低于 proposer 的默认 128 个样本门槛，四轮为随机探索，未启用 LightGBM 引导。
- 2020–2024 已用于排序，不能作为独立样本外结果。尚未做日值物化、相关性去重、公司回测和样本外验证。

最高分候选 `v3_916c0fd580c512b7` 的状态流为：快速隔夜跳空动量、慢速日内实体动量、慢速多日算术动量（m=3, k=2）。研究分数为 1.182508，仅用于本实验内排序。
