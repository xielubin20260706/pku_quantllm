# VeighNa 平台与交易系统架构

## VeighNa 是什么

课程讲义将 VeighNa（曾用名 vn.py）介绍为面向量化交易的开源 Python 平台，覆盖多类交易通道和策略应用。平台项目地址为 [github.com/vnpy/vnpy](https://github.com/vnpy/vnpy)，官方站点为 [vnpy.com](https://www.vnpy.com)。具体支持的接口和功能会随版本变化，实际开发时以当前版本文档为准。

## 交易系统的主要层次

讲义中的系统图可以概括为以下部分：

1. **底层柜台接口**：连接行情和交易柜台，收发行情、委托及成交等数据。
2. **中层引擎**：通过事件引擎传递消息，以 OMS（订单管理系统）缓存维护交易状态，并提供交易指令路由等公共能力。
3. **策略应用**：包括单标的时序策略、多标的组合策略、价差套利等应用。
4. **周边服务**：管理界面、监控、风控和持久化数据库为系统提供运维与保障。

这类分层的价值在于隔离柜台差异、统一数据和业务流程，并让策略运行在相对稳定的公共接口之上。

## 策略引擎的基本职责

策略引擎让同一份策略代码能够在回测和实盘中复用。除调用策略逻辑外，引擎还需处理状态初始化、历史数据和缓存、外部行情及交易数据推送，以及策略主动请求的发送。回测与实盘在数据来源、撮合和运行约束上仍有差别，不能仅凭代码可复用就假设两者结果相同。
