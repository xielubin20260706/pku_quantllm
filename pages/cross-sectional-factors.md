# 截面因子与 vn.py Alpha

## 从选股到因子

截面选股可以从人工判断逐步发展到多因子打分和机器学习。基础量化方法包括单因子选股（如估值、动量或反转特征）和线性组合；更复杂的方法可能使用非线性模型或模型融合。模型复杂度提高不等于有效性提高，必须通过合理的数据切分和样本外评估检验。

## 因子表达式

课程讲义以 K 线中间价变化特征 `kmid` 为例：

```text
(close - open) / open
```

表达式可以用纯数学方式编写，也可以使用 Polars 表达式，例如：

```python
(pl.col("close") - pl.col("open")) / pl.col("open")
```

纯数学表达式直观；使用 Polars 表达式可利用其列式执行能力。实际性能要结合数据规模和运行环境测量。

## 常见算子类别

- **时序算子**：固定合约内跨时间计算。例如 `ts_delay` 取历史值，`ts_mean` 计算滚动均值。
- **截面算子**：固定时间戳下跨合约计算。例如 `cs_rank` 做截面排序，`cs_mean` 计算截面均值。

时序与截面维度不可混淆；在评价因子前要确认算子只使用当时可获得的数据。

## Agent 因子挖掘闭环

1. 明确挖掘方向和经济假设。
2. 生成候选因子公式。
3. 评估因子表现及稳定性。
4. 判断是否继续、修改或停止，并保留实验记录。

生成与评估应形成可复现闭环。需要记录数据范围、计算定义、样本内外划分、评价指标和失败结果，避免只保留表现最好的候选。
