# Agent 开发环境安全

## 基本原则

用户结合其提到的近期 ZCode 事件，给出个人建议：不要在存有个人关键数据的常用电脑上随意安装 Agent 工具。这里仅记录该安全建议，不对事件本身作事实判断。使用代码 Agent 前，先了解其权限边界、文件访问范围、终端执行能力、联网行为和数据处理方式；对需要广泛系统权限的工具，应优先放到隔离、可丢弃的开发环境中使用。

这是一条个人安全建议，不是对任何特定事件或产品的技术结论。选择哪种 Agent，应结合课程要求、供应方文档和自己的风险评估。

## 实践检查项

- 使用专门的开发账户或虚拟机 / 容器，并只挂载作业需要的目录。
- 不把密钥、交易账号密码、个人文件或生产凭据放在 Agent 可访问的位置。
- 对终端命令、依赖安装、文件修改和网络访问保持可见；运行前检查影响范围。
- 代码变更使用版本控制，重要资料有独立备份。
- 不把未经验证的 Agent 生成代码直接连接真实账户或实盘环境。

## 来源

- 来源：用户在项目初始化说明中提供的个人安全建议及其背景描述。
- 以上实践项是面向学习环境的通用整理，具体工具权限以其当前官方说明为准。
