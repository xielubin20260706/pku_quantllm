# SSE50 逐笔撮合回放与 L5 重建

本目录提供 `2026-09-23` SSE50 样本的事件回放脚本。它按同一证券的 `BizIndex` 合并逐笔委托和逐笔成交，维护价格档位及订单剩余量，并按秒输出五档盘口。

## 运行

```bash
python simulate_exchange.py --output-dir exchange_simulation_output
```

依赖：`pandas`、`numpy`、`pyarrow`。

## 输出

- `exchange_simulation_output/trades_replayed_20260923.parquet`：逐笔成交，保留 `exe` 原字段，并增加 `PriceTicks`、`AggressorSide`、`Session`。
- `exchange_simulation_output/l5_1s_20260923.parquet`：每秒 L5，覆盖 09:15–11:30 和 13:00–15:00，午休不补行；价格按元输出，数量为股。
- `exchange_simulation_output/validation_report_20260923.json`：输入文件哈希、重放异常计数、与 `snp` L5/累计成交量/买卖总量的对比结果及差异样例。

## 回放口径

- `FunctionCode=B/S`（66/83）表示买卖方向；`OrderKind=A/D`（65/68）表示新增/撤单。
- 委托与成交按同通道 `BizIndex` 排序；内部价格以 `1/10000` 元整数存储，避免浮点比较。
- `exe` 是实际成交事件流。成交时从簿中扣减可解析的买卖委托；当主动单在 `ord` 中不存在时按已完全成交的主动单处理，并计入 `ghost_aggressor_references`。因此输出成交是逐笔成交回放，不是仅凭 `ord` 独立合成的成交。
- `snp` 用于校验连续竞价时段的五档价量、累计成交量和买卖总量。集合竞价时段输出委托簿重放结果，但不与快照中的竞价指示字段做逐档对比。
- `exe` 中 15:05–15:30 的盘后固定价格成交保留在成交输出中；委托文件没有对应的盘后新增/撤单消息，因此 L5 盘口重建截止 15:00。

## 数据包哈希

用户提供的 SHA-256 是数据包校验值。工作区当前只有三个 Parquet 文件、没有原始压缩包，所以脚本记录各 Parquet 文件 SHA-256，但不能用单文件哈希替代压缩包哈希。

## 模拟交易网页

生成上述 Parquet 输出后，在本目录运行：

```bash
python exchange_web.py
```

浏览器打开 `http://127.0.0.1:8765`。网页支持播放/暂停、单秒前后进、拖动时间轴、按时刻跳转、切换证券，并展示回放时刻的 L5 盘口、最近 60 笔历史成交、逐笔成交聚合的 1 分钟/5 分钟 OHLCV K 线、模拟账户、持仓、委托和模拟成交回报。K 线只显示当前回放时刻前已完成的周期，避免展示尚未发生的成交；模拟成交及未完成委托会标记在图中。模拟限价单可即时吃掉当前可见的对手 L5，剩余数量进入本地模拟队列；之后按历史主动成交方向和同价队列估算成交，可撤销未完成委托。

网页只监听本机回环地址，账户状态只存于服务进程内存；停止服务会清空模拟账户。历史订单簿不会因模拟委托而改变，队列按下单时可见同价 L5 数量近似估算；不计手续费，也不模拟 A 股 T+1。它适合教学演示，不是可用于实盘的交易撮合器。

## L2 数据探索页

生成本地探索报告并启动网页：

```bash
python generate_l2_research.py
python exchange_web.py
```

打开 `http://127.0.0.1:8765/research`，可查看完整 `ord`、`exe`、`snp` 原始记录（逐证券/时段分页，或下载完整 Parquet）、50 只证券的 L2 派生画像、盘中图表和策略特征筛查。用户可提交想法，选择已有特征、方向、周期、分组比例和成本情景，由 `/api/strategy-evaluate` 返回单日样本中的关联方向、收益差和成本敏感性。脚本输出 `exchange_simulation_output/l2_research_20260923.json`。页面不做个股市值大小比较；单日结果用于形成后续研究假设，不用于判断策略是否盈利。
